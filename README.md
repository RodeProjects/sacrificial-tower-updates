# Sacrificial Tower – Update-Kanal

Dieses öffentliche Repository stellt ausschließlich die Windows-Installer und das maschinenlesbare `latest.json` für automatische Programmaktualisierungen bereit. Der Quellcode bleibt im privaten Haupt-Repository.

Endnutzer benötigen weder ein GitHub-Konto noch Git-Zugangsdaten. Die Anwendung lädt neue Installer direkt aus den Releases und prüft Dateigröße sowie SHA-256 vor der Installation.
